# Sales Data Analyzer

## 📌 Description

A Python project that analyzes sales data from a CSV file without using Pandas.

## 🚀 Features

- Read CSV data
- Calculate Total Revenue
- Calculate Total Orders
- Revenue by Category
- Revenue by Product
- Highest Selling Product
- Highest Revenue Customer
- Daily Revenue
- Export Electronics data

## 🛠 Technologies

- Python

## Concepts Used

- File Handling
- CSV Processing
- Lists
- Dictionaries
- Loops
- String Manipulation

## Files

- salesAnalyzer.py
- sales_data.csv
